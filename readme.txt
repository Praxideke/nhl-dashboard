2. ГДЕ ЛЕЖИТ ПРОЕКТ

Путь: E:\AI\NHL

Стек: Node.js (v20+), React, Vite, TypeScript, Fastify (бэкенд), Electron (обертка для .exe).

Где брать данные: Публичный NHL API (api-web.nhle.com), ESPN API (для травм). Наш бэкенд (Fastify) выступает прокси-сервером и кэширует запросы.

3. ЧТО СДЕЛАНО (ТЕКУЩИЙ СТАТУС v1.3.0)

Таблица (Standings): Единый блок <table>, разделена по дивизионам. Есть крупные логотипы (56px), PTS с серым фоном, DIFF (зеленый/красный), Streak (W/L). Есть колонка NEXT (следующий соперник).

Детали матча (GameCard): Открывается по центру, затемненный фон. Внутри: крупные логотипы (100px), полные названия команд, полоса бросков, 3 звезды, авторы голов по периодам (с кликом на игрока).

Карточки игроков и команд: Открываются поверх всего (z-index 1300+). Внутри статистика, состав с травмами, история клубов.

Вкладки: Таблица, Плей-офф (сетка), Лидеры (топ-10).

Стиль: Темная тема, фон main-bg.jpg (текстура льда), «стеклянные» панели (полупрозрачность + blur).

GitHub: Репозиторий Praxideke/nhl-dashboard. Релизы собираются через npm run package.

4. ОСОБЕННОСТИ И БАГИ, КОТОРЫЕ МЫ УЖЕ ПОБЕДИЛИ

Скролл фона: Если открыто модальное окно (матч/игрок), фоновый скролл блокируется через document.documentElement.style.overflow = 'hidden'.

Тултипы: Чтобы избежать багов отрисовки в Electron, тултипы сделаны на чистом CSS (.cell-tooltip:hover > .tooltip-content), без React state.

NHL API: API не всегда отдает nextGame напрямую. Мы запрашиваем расписание на 14 дней вперед глобально и ищем ближайшую игру для каждой команды.

Порт 3001: Если при запуске .exe черный экран — значит, порт 3001 занят старым процессом Node. Нужно убить процесс через Get-NetTCPConnection.
