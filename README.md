# NHL Stats

Десктопное приложение с полной статистикой NHL: турнирная таблица, матчи, плей-офф, лидеры, карточки команд и игроков.

## Скачать

Готовый установщик для Windows — в разделе [Releases](https://github.com/Praxideke/nhl-dashboard/releases/latest):

1. Скачайте `NHL-Stats-Setup-1.0.0.exe`
2. Запустите установщик
3. Ярлык **NHL Stats** появится на рабочем столе

Приложение работает без интернета только для UI — данные тянутся с публичного NHL API. Установка не требует Node.js, всё упаковано внутрь `.exe`.

## Возможности

- **Таблица** — режимы Division / Conference / Wild Card / Overall; точки Last 5 с тултипами; индикаторы клинча (x / y / z); фильтр по дате (архив на любой день в прошлом); выбор сезона от 2014-15 до 2026-27.
- **Матчи** — правая панель с Today's Matches и Fixtures; клик на матч → детали: броски, три звезды, авторы голов с фото, арена, посещаемость.
- **Плей-офф** — сетка: слева Западная конференция, справа Восточная, в центре Кубок Стэнли.
- **Лидеры** — топ-10 полевых (Очки / Голы / Передачи) и вратарей (Победы / SV% / GAA / Сухие игры). Топ-3 в лавровых венках.
- **Карточка команды** — лидеры команды, состав с травмами (IR / OUT / DTD через ESPN API), последние и будущие игры.
- **Карточка игрока** — статистика сезона, карьера, история клубов по сезонам, био.
- **Тёмная тема** — переключатель 🌙/☀️, сохраняется.
- **RU / EN** — полный перевод интерфейса.
